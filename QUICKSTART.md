## ✅ Что внутри

Приложение для отображения показателей на 3.5-дюймовом LCD дисплее с исправленными проблемами зависания.

### Основные функции:
- 📊 **Real-time metrics**: CPU, GPU, RAM, диски
- 💰 **OpenCode AI Go API**: Баланс и использование
- ✨ **Neon animation**: Неоновый трейл эффект
- 🖥️ **Windows integration**: Системный трей

---

## 🎯 Первые шаги

### Шаг 1: Запуск приложения

```powershell
# Перейдите в папку с приложением
cd C:\35inchENG\v2\Turing35NeonV38

# Запустите в тестовом режиме (без анимации)
.\Turing35NeonStableV38_temp.exe --test
```

### Шаг 2: Проверка работы

Приложение должно:
- ✅ Подключиться к COM порту
- ✅ Отобразить начальное изображение
- ✅ Обновлять показатели каждые 130мс (или 2с в тестовом режиме)

### Шаг 3: Использование неоновой анимации

Для включения неоновой анимации:
```powershell
.\Turing35NeonStableV38_temp.exe
```

## 📖 Полезные команды

| Команда | Описание |
|---------|----------|
| `--test` | Тестовый режим (без анимации) |
| `--preview` | Генерация превью PNG изображения |

### Примеры:

```powershell
# Обычный запуск
.\Turing35NeonStableV38_temp.exe

# Запуск в тестовом режиме
.\Turing35NeonStableV38_temp.exe --test

# Генерация превью изображения
.\Turing35NeonStableV38_temp.exe --preview
```

## 🔍 Проверка статуса

### Просмотр логов в реальном времени:
```powershell
Get-Content .\app_v37.log -Tail 60 -Wait
```

**Что искать:**
- ✅ `COM connected=` — успешно подключено
- ✅ `COM write %d/%d bytes success` — успешная отправка данных
- ⚠️ `CTS not asserted` — проблема с сигналом (но приложение работает)

## 🛠 Настройка COM порта

### Изменить COM порт:
1. Создайте файл `com_port.txt` в папке приложения
2. Запишите номер порта (например, `COM5`)

### Изменить скорость передачи:
Редактируйте исходный код `main_v38.go`:
```go
cfg.BaudRate = 230400 // Текущее значение
```

## 📊 Мониторинг стабильности

### Проверить работу > 30 минут:
1. Запустите в тестовом режиме `--test`
2. Откройте журнал через трей → Открыть лог
3. Следите за сообщениями в логе

### Хорошие показатели:
- Минимум предупреждений о CTS
- Регулярные обновления показателей
- Стабильная работа неоновой анимации

---

## 🆘 Быстрая помощь

### Если экран завис:

1. **Попробуйте перезапустить через трей** → Правый клик на иконке → Выход → Запуск заново
2. **Отключите и подключите USB-кабель** (если не помогло)
3. **Проверьте журнал**: `app_v37.log` для сообщений об ошибках

### Для диагностики:
```powershell
# Посмотреть последние ошибки
Get-Content .\app_v37.log -Tail 20

# Проверить статус COM порта
Get-CimInstance Win32_SerialPort | Where-Object { $_.Name -match '^COM\d+$' } | Select-Object Name,Status
```

## 💡 Советы по использованию

### Для максимальной стабильности:
- ✅ Всегда запускайте сначала в тестовом режиме (`--test`)
- ✅ Следите за журналом при первом запуске
- ✅ Обновляйте драйвер CH340 до последней версии
- ✅ Используйте качественный USB-кабель

### Рекомендации по мониторингу:
- Проверять журнал раз в 30 минут для длительного запуска
- При появлении предупреждений о CTS проверять состояние порта
- Следить за использованием системных ресурсов
