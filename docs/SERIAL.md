# Turing/CH340 — управление дисплеем

- 480×320, RGB565 little-endian, serial baud 230400, аппаратный RTS/CTS.
- Команды: HELLO 69, CLEAR 102, SET_ORIENTATION 121 (landscape=2), DISPLAY_BITMAP 197.
- 6-байтный заголовок: x(10) / y(10) / ex(10) / ey(10) / command(8).
- Полный кадр передаётся только при старте и при восстановлении после сбоя. Дальше отправляются изменённые прямоугольники через единый последовательный worker. В момент отправки COM-порт принадлежит ровно одному процессу.
- После ошибки WriteFile нельзя продолжать частичные обновления: это вызывает полосы и порчу кадра. Worker закрывает COM, переподключается и начинает с полного кадра.

Режим `--preview` не требует устройства. Настоящую работу драйвера проверить можно только на Windows c подключённым экраном.
