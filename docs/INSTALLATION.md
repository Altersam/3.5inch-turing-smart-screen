# Установка и настройка Turing 3.5 Neon Monitor V38

## 📦 Требования

- Windows 10/11 (64-bit)
- USB порт с устройством CH340
- Go 1.23+ (для сборки из исходников)

---

## 🔧 Быстрая установка готового EXE

### Шаг 1: Скопируйте готовый файл

Скопируйте файл `Turing35NeonStableV38_temp.exe` в нужную папку:

```powershell
copy "C:\35inchENG\v2\Turing35NeonV38\Turing35NeonStableV38_temp.exe" "."
```

### Шаг 2: Запустите приложение

```powershell
cd C:\путь\к\приложению
.\Turing35NeonStableV38_temp.exe --test
```

---

## 🔨 Установка Go для сборки из исходников

### Шаг 1: Скачивание Go

1. Перейдите на [официальный сайт Go](https://go.dev/dl/)
2. Скачайте `go1.23.x.windows-amd64.zip` или `.msi`
3. Распакуйте ZIP в `C:\go` или установите через MSI

### Шаг 2: Добавление Go в PATH

**Способ А: Через системные настройки Windows**

1. Нажмите Win + R, введите `sysdm.cpl`, нажмите Enter
2. Вкладка "Параметры среды", кнопка "Переопределение среды"
3. В системе → Создать переменную `PATH` со значением `C:\go\bin`
4. Перезапустите PowerShell и Terminal

**Способ Б: Через командную строку (быстро)**

```powershell
[System.Environment]::SetEnvironmentVariable("PATH", $env:PATH + ";C:\go\bin","Machine")
```

### Шаг 3: Проверка установки

Откройте новую консоль PowerShell и выполните:

```powershell
go version
```

Если видите версию (например, `go version go1.23.0 windows/amd64`), Go установлен правильно!

## 🔍 Диагностика проблем

### Просмотр журнала в реальном времени:

```powershell
Get-Content .\app_v37.log -Tail 60 -Wait
```

**Ищите эти сообщения:**
- ✅ `COM connected=` — успешное подключение
- ✅ `COM write %d/%d bytes success` — успешная отправка данных
- ⚠️ `CTS not asserted` — проблема с сигналом готовности к приёму

### Проверка состояния COM порта:

```powershell
Get-CimInstance Win32_SerialPort | Where-Object { $_.Name -match '^COM\d+$' } | Select-Object Name,Status
```

### Проверка драйвера CH340:

```powershell
Get-PnpDevice | Where-Object { $_.FriendlyName -like "*CH34*" } | Select-Object FriendlyName,Status
```

## 🔧 Настройка COM порта

### Изменить COM порт:

1. Создайте файл `com_port.txt` в папке приложения
2. Запишите туда номер порта (например, `COM5`)

### Изменить скорость передачи:

Редактируйте `main_v38.go` и измените значение:
```go
cfg.BaudRate = 230400 // Текущее значение
```

## 📞 Поддержка

Если приложение продолжает зависать:

1. **Проверьте журнал:** `app_v37.log` на наличие сообщений о CTS
2. **Переподключите USB-кабель:** Снимите и установите в Диспетчере устройств → Порты (COM и LPT)
3. **Попробуйте другой порт:** Используйте другой USB-порт или кабель
4. **Обновите драйвер CH340:** Скачайте последнюю версию с сайта TP-Link/Realtek
